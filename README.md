# Світло? — Android (чистая Java, без зависимостей)

- minSdk 7 (Android 2.1), targetSdk/compileSdk 35, ни одной внешней библиотеки, весь UI рисуется кодом.
- Сборка: Android Studio (Ladybug+) → Open, либо `gradle wrapper && ./gradlew assembleRelease` (JDK 17).
  Если инструмент не принимает minSdk 7, поставьте 9 в `app/build.gradle`, код от этого не меняется.
- Сервер: `http://uae1.alwaysdata.net/` (cleartext разрешён в манифесте).

## Структура
- `MainActivity` + `Screen` — навигация внутри одной Activity.
- `MainScreen`, `LocationScreen`, `RegionScreen`, `GroupScreen`, `NameScreen`, `SettingsScreen` — шесть экранов макета.
- `Ui`, `IconView`, `SvgPath`, `Icons` — вёрстка по координатам макета (1 ед. макета = 0,5dp) и иконки из SVG-путей.
- `Repo`, `Schedule`, `Api`, `Groups`, `Store`, `Region`, `S` — данные, разбор TSV, сеть, перебор групп, хранилище, строки uk/en.
- `Scheduler`, `Updater`, `AlarmReceiver`, `BootReceiver`, `UpdateService`, `Compat` — фон, уведомления, совместимость версий.

## Звуки уведомлений
Свои тихие «колокольчики» в `app/src/main/res/raw/` (Ogg Vorbis, моно, до 0,6 с):
- `snd_neutral` — смена графика и все прочие сообщения (один мягкий удар);
- `snd_happy` — «Світло увімкнуть через…» (второй удар чуть выше, на терцию);
- `snd_sad` — «Світло вимкнуть через…» (второй удар чуть ниже, на терцию).

Android 8+: три канала `change_v2` / `on_v2` / `off_v2`, старые `alerts` / `changes` удаляются (звук канала после создания не меняется).
Android 3.0–7.1: `setSound()`, 2.x: `Notification.sound`. Если свой звук не удался, уведомление придёт с системным.
`res/raw/keep.xml` не даёт шринкеру вырезать звуки (они берутся по имени).

## Проверка звуков
10 быстрых тапов (пауза между тапами до 2 с; вид не выглядит и не ведёт себя как кнопка) по названию «Світло?» на главном экране показывают по очереди три пробных уведомления: нейтральное, «увімкнуть», «вимкнуть».

Группы региона берутся одним запросом `GET /<регион>/` (нужен API v3); со старым сервером приложение само переходит на перебор.
